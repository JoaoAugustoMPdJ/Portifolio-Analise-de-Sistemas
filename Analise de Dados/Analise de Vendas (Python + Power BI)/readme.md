#  Análise de Vendas – Superstore (Python + Power BI)

##  Sobre o Projeto

Este projeto tem como objetivo realizar uma análise exploratória e analítica de dados de vendas de uma empresa fictícia utilizando Python para ETL (Extração, Limpeza e Transformação) e Power BI para visualização e análise interativa dos dados.

O foco principal do projeto é demonstrar a construção de um pipeline de dados profissional, desde o tratamento dos dados até a entrega de insights por meio de dashboards.

## Objetivos da Análise

- Calcular o faturamento total da empresa  
- Calcular o lucro total e a margem de lucro  
- Identificar as categorias de produtos com maior volume de vendas  
- Identificar as regiões mais lucrativas  
- Avaliar o impacto dos descontos no lucro  
- Gerar um dataset limpo e padronizado para consumo no Power BI  

>  Observação:  
> O dataset utilizado não possui colunas temporais (datas). A análise é focada em desempenho comercial, categorias e regiões.

##  Ferramentas Utilizadas

- Python 3  
- Pandas  
- Matplotlib  
- Power BI Desktop

## Pipeline de Dados

1. Extração dos dados a partir do CSV original  
2. Limpeza e padronização dos dados  
3. Cálculo de KPIs de vendas e lucratividade  
4. Exportação dos dados tratados para integração com Power BI  

##  Principais Análises Realizadas

###  Indicadores Gerais
- Faturamento total  
- Lucro total  
- Margem de lucro  

###  Vendas por Categoria
Análise do faturamento por categoria de produto.

###  Lucro por Região
Análise da lucratividade por região.

###  Impacto de Descontos
Avaliação da relação entre descontos aplicados e lucro obtido.

## Principais Insights

- Algumas categorias concentram maior faturamento, mas nem sempre maior lucro  
- Regiões apresentam diferenças significativas de rentabilidade  
- Descontos elevados impactam negativamente a margem de lucro

## Dashboard de Vendas – Superstore

Dashboard desenvolvido no Power BI com base em dados de vendas, com foco em análise exploratória e visualização de indicadores de negócio.

### Indicadores principais:
- Total de vendas
- Lucro total
- Quantidade de itens vendidos

### Análises:
- Vendas por região
- Vendas por categoria
- Lucro por categoria

### Ferramentas utilizadas:
- Power BI
- Modelagem de dados
- Visualização de dados
